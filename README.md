## 📌 Overview

**Pack2Zip** is a lightweight, closed-source web tool that converts **Modrinth `.mrpack`** files into standard **`.zip`** archives.

It is built for users who want:
- Easy sharing of modpacks
- Simple backups
- Better compatibility with launchers and tools

You **do not** need:
- Installation ❌
- Accounts ❌
- Technical setup ❌

Just:
➡️ Upload `.mrpack`  
➡️ Click convert  
➡️ Download `.zip`
